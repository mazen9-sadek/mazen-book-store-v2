# مكتبة مازن - Book Store V2

موقع طلب كتب دراسية متصل بـ Google Sheets.

## المميزات

- عرض الكتب حسب الصف الدراسي
- البحث عن الكتب
- سلة مشتريات
- إرسال الطلبات إلى Google Sheets
- رقم طلب تلقائي
- لوحة إدارة
- إحصائيات
- تغيير حالة الطلب
- إدارة الكتب من لوحة الإدارة
